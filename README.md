# نظام المنيو الإلكتروني للمطاعم

نظام متكامل لإدارة المنيو واستقبال الطلبات للمطاعم والكافيهات.

## النشر على Render.com (مجاني)

1. ارفع هذه الملفات إلى GitHub Repository
2. اذهب إلى Render.com وسجل بحساب GitHub
3. اضغط New + → Web Service
4. اختر الريبو الخاص بك
5. أضف متغير البيئة DATABASE_URL (من Neon.tech أو أي PostgreSQL مجاني)
6. اضغط Deploy

## بعد النشر

1. افتح الرابط الذي يعطيك إياه Render
2. استخدم seed.js لإدخال البيانات التجريبية (من خلال Render Shell)
3. جرب النظام من المتصفح

## المميزات

- عرض المنيو حسب الأقسام
- إضافة أصناف للسلة
- إرسال الطلبات لحظياً عبر Socket.io
- شاشة مطبخ للطلبات النشطة
- لوحة تحكم لإدارة الطلبات
- دعم كامل للغة العربية
